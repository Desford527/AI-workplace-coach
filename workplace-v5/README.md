# AI职场沟通训练师 v5.1.0

基于 AI高压沟通教练 v4.18 的 Python 本地改造版。此版本按用户明确授权，随项目提供其指定的完整默认 API 配置，启动时自动替换原 API 条目。

## 海外客户与英语表达提升

在「沟通训练」选择「海外客户 · 英语」，再选择英文交付协调或技术需求会议。可展开三轮虚构示例，对照较弱/改进表达；点击「使用此示例目标与背景」后再开始训练。

对话用英文，解读与复盘用中文。结束后新增「英语表达提升」：原句、英文改写、中文解释、技术术语和下一次练习。原句引用校验通过后才保存；模型未返回有效补充时保留六维复盘并显示说明。旧记录无该字段仍可查看。语言建议不参与原六维平均分，文本不评价发音、听力或英语等级。

详见 [海外客户英语演示与验收](OVERSEAS_DEMO.md)。

## 直接启动

需要 Python 3.10 或更新版本。

- Windows：解压后进入 `workplace-v5`，双击 `start.bat`。
- macOS/Linux：执行 `bash start.sh`。
- 手动：`python server.py 8000`。

启动器会打开当前版本的实际地址。默认端口 8000，若旧服务占用，则顺延；不要继续使用旧版标签页或端口。页面底部及启动终端应显示 v5.1.0。旧服务器窗口可以先关闭。

## 此版本的默认 API

- 配置名称：`DeepSeek527`
- 地址：`https://api.deepseek.com`
- 对话模型：`deepseek-flash`
- 复盘模型：跟随对话模型
- API Key：随 `default-api.json` 提供用户所指定的值，不在文档或日志中回显。

首次启动自动读取随版本的配置，将本机旧 API 条目移除并设为上述默认配置。无需填写 Key，无需点击替换按钮。旧 `deepseek-cbx`、`deepseek-v4-flash` 与浏览器缓存不会覆盖新版默认配置。当前活动配置 ID 尽量保留，已保存对话、画像与历史不删除。

此版本已应用后，可继续正常编辑或新增多 API 配置；再次恢复旧 cbx/v4 条目时，启动会重新应用本版本的默认配置。自动替换不会发起模型请求；实际测试或训练才会调用服务商。

## HTTP 402

DeepSeek 返回 HTTP 402 表示账户余额不足，需要到官方控制台检查余额和充值。默认配置替换不能解决服务商计费问题。程序保留用户原话，余额恢复后可重试。

## 已实现功能

8 个职场场景、对象画像查看/新建/编辑、冻结场景与画像快照、中文及英文连续对话、原话三层解读、六维及每轮平均总分、逐轮复盘、只读长期画像、SQLite 持久化、失败重试、HTML/JSON 导出及打印/PDF。模型协议使用 OpenAI 兼容 Chat Completions，仍支持多个服务商以及独立复盘模型。

评分固定为结论清晰、证据具体、诉求对齐、边界与风险、下一步行动、理解与协作。每维 0–100 整数，总分按六维平均四舍五入；原话引用、维度与逐轮覆盖严格校验。模型失败时不伪造成功。

记录存于 `user_data/workplace.sqlite3`，配置存于 `user_data/apiconfig.json`。备份时先停服务再复制整个 `user_data/`。画像单次支持最多 100 场成功复盘。旧五维 JSON 原样保留，完整旧对话可重新六维分析。

## v5.0.5：模型 JSON 格式兼容

DeepSeek 官方端点默认使用 response_format 的 json_object 模式。其他 OpenAI 兼容端点保持原调用协议；显式启用 JSON 模式但服务商明确不支持时最多回退一次。正文中的单个 JSON 对象可位于代码块或说明文字中，支持思考标签、分段文本和双重编码；多个顶层对象、无效分数和虚构证据仍拒绝。

格式或结构化字段错误会自动请求模型修正一次，可能产生一次额外模型调用；不会重复保存用户回应，不会把 HTTP 402、认证错误或网络错误当作格式问题重试。评分、轮次、原话证据继续严格校验。

若仍失败，诊断保存到本机 user_data/model-response-last-error.json，包含最后模型正文片段及结束原因，Key 会过滤，不会通过静态网页或导出报告公开。截断、空正文和仅返回思考过程会显示具体提示。当前云测试被 DeepSeek 域名的网络策略拦截，替身及浏览器验收不代表真实模型通过。

## v5.0.6：先进入复盘，再生成结果

点击「结束并复盘」会立即进入本次训练复盘页，隐藏聊天和输入框，保留完整对话并显示生成状态。模型失败、余额不足或连接中断时也保持在复盘页，可重新生成、查看记录或导出；不会弹出校验红框把用户挡在聊天页，也不会把失败当成有分数的成功。没有用户回应的训练可结束，但不生成虚构评分。

结束状态在模型调用前保存；刷新可继续查看生成状态，服务重启后中断的生成可直接重试。成功复盘独立保存，画像更新失败不丢失结果。

下轮计划接受多条或多行实际模型建议，前四条优先显示，其余折叠保留；缺少单独计划时复用该次 AI 复盘已有的调整措施。可选说明缺失不再丢弃有效评分，评分和逐轮原话引用仍严格校验。

更新时关闭旧服务，用新版程序文件（包含 web 目录）更新，保留 user_data 与 skills，然后重启并强制刷新浏览器。此前的 API 默认值和 Key 沿用，无需重新填写。

## v5.0.13：自由输入与沟通经验库

页面最下方新增「想改什么，直接说」，保留所有原表单。沿用当前启用的 OpenAI 兼容 API，AI 将输入整理成限定的本机资料操作，不执行代码，也不通过此入口修改 API、删除对象、改写历史或评分。一次输入可包含多项需求：

- `我想新增一个对象，王工是测试负责人，特别重视验证过程和异常闭环。`

- `收录一条沟通经验：汇报延期时，先说明对交付的影响，再给恢复计划和需要对方决定的事项。`

提交后直接保存，并列出办理结果；资料不足时在框内追问，没有先行修改。补充画像采用追加方式，不覆盖旧描述；语录必须逐字来自用户明确记录的原话。用户观察与 AI 模拟补充不当作已经核实的人格事实。语录更新后，可在「语录与分析」重新生成带引用依据的特征分析。办理记录保存在本机，同一请求重复提交不重复追加。

追问强度仍为温和、标准、深入三级。在进行中的训练里调整，作用于后续模型回应并记录变更；同时作为下次训练默认值。已结束的训练不修改。对象和经验修改只用于新训练，已开始的对象快照、对话和评分保留。表单的强度选择也会保存为下次默认值。

「沟通经验库」位于对象画像与我的画像之间，内置 8 条通用经验，覆盖结论与证据、决策请求、技术验证边界、客户异议、追问、行动闭环、跨语言协作及行为观察。支持搜索、手工添加、导入 TXT / Markdown / JSON，以及导出完整 JSON。文本文件作为一条经验导入，每条正文最多 6000 字；JSON 一次最多 100 条，每条含 `title`、`content`，可选 `category`。导入整批先校验，相同标题和内容跳过重复。

新训练按场景优先选取最多 6 条经验并保存快照（合计最多 12000 字），供对话及复盘参考。经验不增加评分维度，也不作为事实证据，长条目超出引用预算时不纳入本轮。导入内容会随训练资料发送到当前选择的模型服务商，建议使用脱敏内容。手工添加和文件导入不调用模型；自由输入需要一次模型调用，格式不合格时最多再修复一次，调用沿用现有计费。

## v5.0.14：从会议纪要积累训练资料

新增「会议纪要」页，支持粘贴正文，或导入 TXT / Markdown / Word（DOCX）。DOCX 在本机提取普通段落及表格中的文字，不执行宏、不读取外部链接；文本兼容 UTF-8、带 BOM 的 UTF-16 和 GB18030。文件最大 5 MB（纯文本最大 1 MB），提取后正文最多 60000 字。旧 DOC、PDF、图片和扫描件请先转成可复制文本或 DOCX；没有 OCR 功能。

使用流程：

1. 点击「会议纪要」，选择文件或粘贴已脱敏的正文，补充会议标题。尽量保留人物称呼、发言归属、项目名称、决议与责任人。文件读取只在本机完成；点击「AI 提取并预览」才会把正文交给当前启用的 API 服务商。
2. 查看提取预览：按人物分组的工作关注点、谨慎性格推测、纪要记载语句，以及项目现状/风险/决议/行动项、可复用沟通经验。每项可展开原文依据。依据必须逐字存在于纪要中，语句与说话人必须有同段依据；间接转述不应当成直接语录。
3. 核对人物和项目归属，可以归入已有对象/项目，也可以新建。同名多人不会自动匹配；必须明确选择。模型推测单独标注，不作为稳定人格或确定心理事实。没有明确项目名称时不编造项目，可以补全正文后再分析。
4. 默认勾选尚未保存的条目，取消不需要的项，再点击「保存勾选结果」。本次所有条目校验通过后一次提交；失败不留下部分画像修改。未勾选条目可以在「纪要与提取记录」重新打开后继续保存。
5. 在训练页「项目背景」选择项目，背景自动填入，可继续编辑、精简或脱敏后开始。模型使用本次编辑后的背景；完整项目快照保存在本机训练记录中，模型只额外收到项目 ID 与名称。会议生成的经验进入经验库，由新训练按场景参考。

对象资料采用追加并注明会议来源，原描述保留；语录去重并可使用原有「语录与分析」继续生成有依据的特征推测。纪要记载不等同于录音逐字稿，请在预览时核对发言归属。会议内容和提取结果本机持久化；相同正文重复导入返回原预览，不再请求模型；已保存条目重复点击不会重复追加。更新与新增只用于未来训练，不改写已有训练快照、原话或评分。API 配置与默认 Key 不重置。

本版新增 `meetings.py`，与其他新版代码一起更新。仍只需要 Python 3，无新增运行依赖。Windows 双击 `workplace-v5/start.bat`，Linux/macOS 运行 `bash workplace-v5/start.sh`；更新时保留原 `user_data`，关闭旧服务，并确认页脚为 v5.0.14。真实模型提取质量需要结合你自己的脱敏纪要验证。
