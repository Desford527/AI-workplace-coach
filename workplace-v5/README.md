# AI职场沟通训练师 v5.0

由 AI高压沟通教练 v4.18 的 Python 服务器副本改造，运行时仅使用 Python 标准库。保留原配置/manifest/coach/quotes 接口和原始 skills；新增完整工作流，不依赖在线 Worker，也不发布到原 Site。

## 本地启动

需要 Python 3.10 或更新版本，以及现代浏览器。

- Windows：双击 `start.bat`。
- macOS / Linux：在本目录执行 `bash start.sh`。
- 手动：`python server.py 8000`（macOS/Linux 可用 `python3`）。

打开启动终端输出的地址，默认 `http://localhost:8000`。端口占用时在 8000–8005 内顺延，终端窗口需保持运行。程序只监听本机，不暴露到局域网。不要双击 HTML 文件。

## 先保护现有原项目

交接包只有空配置，不包含您的真实训练库或密钥。`handoff-source/coach-codex-handoff/original-v4.18` 是未经修改的来源备份；`workplace-v5` 是开发副本。不要用空 `apiconfig.json` 覆盖原项目。

若电脑上有原项目，在 `workplace-v5` 目录运行下列命令，目标必须是尚不存在的新目录：

```bat
python migrate_local.py --source "D:\Projects\原项目" --destination "D:\Projects\AI职场沟通训练师-v5"
```

macOS/Linux 同理，使用实际路径和 `python3`。迁移工具只读取原目录，保留原 `user_data`、配置、历史文件和自定义 skills，并将原目录备份至新目录的 `legacy-backup/`。它不输出密钥，也不覆盖已有目标目录。启动迁移后的新目录。

API 配置保持 `apis + active` 格式；单配置旧格式会在读取时兼容，不自动改写原文件。新页面在同一浏览器来源发现 `ahc_api_cfg_v1` 时，只在服务器没有配置的情况下导入；已有服务器配置始终优先，浏览器原值保留。迁移页面端口变更可能改变 localStorage 来源，请保留原浏览器配置或使用原项目配置文件。

原 v4.18 交接源码只使用 localStorage 保存 API 配置，没有已实现的历史/长期画像持久化逻辑。因此无法声称自动识别本机其他修改版的任意历史格式。现有文件原样保留；新版「训练记录 → 导入旧版 JSON」可保留未知 JSON 和五维评分，不补造六维分。含完整 `messages[{role,text/content}]` 或原式 `opening/userMsgs/hpLines` 的 JSON 可重新 AI 分析：先在训练页确认场景、对象、目标，再在旧记录中点击重分析。缺完整对话的记录只能原样查看。

## 多 API 设置与真实模型

在本机网页右上角「API 设置」填写名称、Base URL、Key、对话模型和可选复盘模型，保存并启用后测试连接。保留任意 OpenAI 兼容服务商，不强制 OpenAI Responses。

地址规范：根地址或 `/v1` 会补 `/chat/completions`；已经是完整端点则不重复追加；自定义路径与查询参数保留。远程必须用 HTTPS，本机 `localhost/127.0.0.1` 免密模型允许 HTTP。服务商必须支持 `messages`、`model`、`temperature` 与文本 JSON 回复。代码不强制服务商专有 `response_format`，不限制固定模型列表。密钥空白保存表示保留已有密钥，需清除时显式勾选。

模型调用由本机 Python 转发，浏览器不直接跨域访问服务商。新接口读取配置仅返回 `hasKey`；原 `GET /api/config` 为兼容仍提供配置给本机受信页面。静态目录拒绝读取隐私文件，跨来源请求被拒绝。密钥以明文保存于本机 `user_data/apiconfig.json`，不要提交、分享或打印该文件。模型请求包含训练背景、画像和记录，会发送到您选择的服务商；请先脱敏。

默认模型超时 90 秒，可用 `COACH_MODEL_TIMEOUT` 修改（最大 180 秒）。超时、认证错误、服务商错误、非法 JSON、分数缺失/越界和不存在原话引用均明确报错，不伪造 AI 成功。未配置模型时可查看界面与配置，但不会生成规则假对话。测试替身仅位于 `tests/`，正常程序不会自动启用它。

## 功能与数据

8 个职场场景：进度/决策、资源协调、技术评审、异常/风险、客户需求、交期协调、英文需求、英文延期。英文场景英文对话、中文解读/复盘，英文改进示范。

对象画像可查看、新建、编辑；已知事实与推断分开。训练开始冻结画像、目标、背景与强度，后续编辑不改变历史。我的沟通画像只读，由成功复盘后的真实原话生成，包含来源消息、样本量、更新时间、观察可信程度与练习措施。

六维固定为结论清晰、证据具体、诉求对齐、边界与风险、下一步行动、理解与协作；每维为 0–100 整数，每场及每条回应总分均为六维平均四舍五入。评分标准写入模型提示词。每维必须有依据及存在于实际用户消息中的原话，逐轮点评覆盖所有回应。SVG 雷达图、文本分数、HTML/JSON 导出和打印/PDF 均支持。

本机 `user_data/workplace.sqlite3` 保存完整对话、快照、六维评分、画像、旧记录和请求幂等状态。失败回应保留原话，「重试模型回应」不重复提交；生成中禁止重复发送；刷新会恢复最近训练。中断保留记录，新的再练不会串入旧消息。复盘先保存，画像生成失败独立提示并可重试。画像当前支持一次读取最多 100 场成功复盘，超限明确报错且复盘不丢；尚未实现分批长期画像归并。

完整 HTML 报告包含内联样式、雷达图、逐轮依据、三层解读和完整对话，可离线打开；不包含 API 配置。打印前自动展开证据。JSON 包含训练数据，不包含 API Key。导出文件仍可能包含训练内容，请按实际隐私要求保存。

备份数据库时先停止程序，再复制整个 `user_data/`（含可能存在的 WAL/SHM），也可以从页面导出单场 JSON。不要在运行中只复制 SQLite 主文件。

## v5.0.1：连接测试成功，旧训练仍提示未配置

连接测试使用设置窗口选中的配置；训练保留创建时的 API 配置 ID。如果旧配置被删除、重建或导入数据不再包含该 ID，旧训练不能沿用它。v5.0.1 会明确提示失效绑定，并提供「使用当前 API 配置」按钮。

先保存并启用所需配置、测试连接，关闭设置，点击训练页「使用当前 API 配置」，再点击「重试模型回应」。切换保留原话、目标和对象画像快照，保存配置切换历史；不会自动发起付费模型请求。连接测试成功不会被冒充成开场已经生成。

更新时先关闭旧服务窗口，再从 GitHub 下载本分支最新源码。若保留原目录，只需用新版 `workplace.py`、`index.html`、`web/app.js` 覆盖对应程序文件；不要覆盖 `user_data/`、`skills/` 或个人配置。重新启动服务并在浏览器按 Ctrl+F5 强制刷新。也可以对旧目录用 migrate_local.py 创建全新副本。
