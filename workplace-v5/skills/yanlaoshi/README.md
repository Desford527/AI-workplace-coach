# AI高压沟通教练 — WorkBuddy Skill

这是“AI高压沟通教练”的 WorkBuddy 可导入 Skill 包。

## 导入

在 WorkBuddy 中进入“专家·技能·连接器 / Skills”管理页，选择“上传技能 / 导入本地技能包”，上传整个 ZIP 包。

- 开始训练
- 我想跟朱总对话
- 我想跟严工对话

- 模拟一个很难沟通的领导追问我

- 我想创建一个新的领导，我对他的印象是……
