# 修改记录

## v5.0.4 · 2026-10-12

- 按用户明确授权，将指定 DeepSeek527 完整配置随版本交付，包括所指定的 Key。
- 首次启动自动删除旧 API 条目并应用 DeepSeek527/官方地址/deepseek-flash，无需填写或点击替换按钮。
- 保留原活动配置 ID、对话、画像与历史；版本应用后保留后续正常编辑。
- 移除额外的替换按钮；启动器自动打开当前版本实际端口，避免误复用旧版本服务。

## v5.0.3 · 2026-10-12

- 新增明确的 DeepSeek527 默认配置替换操作：移除旧 API 配置，固定官方地址与 deepseek-flash，复盘模型跟随对话模型。
- 强制安全输入新 Key，不沿用旧密钥；保留当前配置 ID 以继续旧训练，保留历史和画像。
- 普通多 API 编辑行为保留；替换仅在用户点击该操作并保存后执行。

## v5.0.2 · 2026-10-12

- HTTP 402 明确提示账户余额/计费问题，失败时继续保留用户原话。
- 新增 API 表单默认填写 DeepSeek527、官方地址及 deepseek-flash；密钥仍仅从本机安全设置读取，不放入源码或下载包。
- 增加余额不足的错误提示及原话保留测试。

## v5.0.1 · 2026-10-12

- 修复当前配置连接测试成功，但旧训练仍绑定已删除配置时的误导提示。
- 新增「使用当前 API 配置」：显式切换本轮模型配置，保留原话和冻结画像，记录切换历史；不自动重新发起付费请求。
- 测试成功清除过期的全局配置错误，旧训练配置失效时给出对应操作。
- 新增旧配置删除、当前配置测试通过、切换后重试且原话不重复的回归测试。

## v5.0 · 2026-10-12
