## 尚未实测 / 限制

- 没有用户模型配置与授权密钥，真实模型的开场、两轮、评分质量、画像质量、服务商认证/额度/延迟尚未验证。替身通过不代表上述真实行为通过。
- 您本机原项目路径尚未提供；此云环境不能直接读取电脑磁盘。迁移工具经过模拟数据测试，但没有对真实用户配置、历史或本机修改版执行迁移。原版交接源码只持久化 API，没有完成历史库；未知旧格式只原样保存，不推测数据含义。
- Windows start.bat 和 build_exe.bat 已更新，但此 Linux 环境未在 Windows 实测，也未交付构建好的 exe。源码可通过 Python 启动。
- 未用实体手机、Windows 高 DPI 桌面或实际打印机测试；手机视口和 PDF 已验证。
- 长期画像一次处理最多 100 场成功复盘，未实现分批归并；超限会明确提示，成功复盘仍保存。
- 不支持非 OpenAI 兼容的服务商专有协议；当前远程服务需兼容 Chat Completions 的 messages/model/temperature 和文本 JSON。缺少所需输出字段时明确报错并重试，不用规则假结果替代。

## 本机真实验收步骤

1. 如果已有原项目，先停止原程序，在全新目标目录运行 README 中的迁移命令；确认旧目录及配置仍在。
2. 启动新目录，在本机 API 设置中读取已有配置，或安全填写服务商信息；聊天中不要贴 Key。
3. 测试连接；中文场景开始、至少回应两次、结束复盘；确认六维、每轮平均分、证据原话、三层解读、长期画像。
4. 刷新确认对话/复盘/画像保留；再验证英文场景、HTML 导出、打印/PDF。
5. 如模型返回协议错误，用已保存的记录重试；不要将替身或规则练习误报成真实模型验收。
