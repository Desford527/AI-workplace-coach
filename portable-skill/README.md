# 可迁移沟通训练Skill

本包不含API密钥、客户资料或历史记录。

- 原生支持Skill的Agent：将workplace-communication-coach文件夹导入其Skill目录，按宿主方式启用。
- 支持附件/自定义指令的AI：上传SKILL.md和references/report-template.md，再明确要求按附件执行。仅上传ZIP不代表平台会自动解压识别；必要时分别上传两个Markdown文件。
- 语音演示：先在文字会话中加载文件并确认训练规则，再在支持共享该会话上下文的语音模式中训练。是否能在语音中访问附件由宿主决定，先验证。

可复用角色模拟、英文训练、六维复盘、表达优化、纪要整理等核心方法。网页数据库、配置管理、跨会话持久化和交互图表仍需应用实现。不能保证所有AI软件原生支持Skill。

快速开始见VOICE_DEMO.md。
