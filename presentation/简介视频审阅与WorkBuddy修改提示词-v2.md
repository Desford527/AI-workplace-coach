# 48秒简介视频审阅与修改建议

审阅对象：用户提供的《AI职场沟通训练师_48s.mp4》，实际48秒，含音轨。本次具体意见针对逐段画面与时序；下面旁白是建议稿，不是原视频转写。

## 优先修改

1. **开场压缩，品牌更早出现。** 当前0–10秒主要在等待问题气泡出现，人物集中在底部且偏小；把被追问的瞬间压缩到前5秒，第5秒引入项目。开场只用一个核心问题“周五能交付吗？”，配一句模糊回答，减少观众理解负担。
2. **把亮点变成可见变化。** 对象卡片不只列职位，要显示不同关注点；表达优化、直接说都用清楚的输入→结果对照。海外场景突出“英文对话＋中文复盘”，不用一张缩得很小的长聊天截图承担说明任务。
3. **六维复盘讲改法。** 当前约24秒雷达图与右侧分数表重复呈现同一组数据。保留雷达图，另一半改为“诉求对齐58 → 请对方明确做什么决定”的具体建议。若加总分，这组72/64/58/74/68/72的平均为68；72是结论清晰分，不能当总分。
4. **表达优化是记忆点。** 目前约28–33秒整理器方向很好，但主体仍偏小。把原话和优化句放到画面中央并增大，原话→整理→结果，结果稳定显示至少2秒。
5. **直接说值得单独突出。** 当前约40秒附近标题、输入条和人物都很淡，观众可能来不及看清。让“增加追问强度”清楚出现，随后“标准→深入”，再冒出一个具体追问。主体阅读期间维持完整可见，不长时间淡入淡出。
6. **经验积累讲清回路。** 卡片不只是进仓库；明确“会议纪要/语录/经验 → 画像与资料 → 下一轮练习”，让观众理解为什么越用越贴近工作。
7. **删装饰、保节奏。** 减少无意义漂浮粒子和角落里的小人物。每段一个主焦点，转场为内容服务。最终稿以实际旁白节奏校准，目标约55秒，必须少于60秒。

## 建议节奏与旁白

|时间|画面重点|旁白建议|
|---|---|---|
|0–5秒|一个关键问题＋主角短暂停顿|材料准备了很多，关键追问，还是可能答不清。|
|5–10秒|项目名称＋提前预演|AI职场沟通训练师，让重要沟通提前练。|
|10–17秒|对象关注点不同，最后带海外英语|面对不同对象，练习不同沟通。海外客户，也能用英文交流。|
|17–25秒|原话→六维分析→具体建议|练完不只看分数，更能回到原话，知道哪里需要改。|
|25–33秒|情绪原话→表达整理器→合理诉求|临时想说的话，也能先优化。把情绪，整理成合理诉求。|
|33–40秒|自然语言输入→设置变化|想调整，直接说。一句话，让训练更贴合自己的需要。|
|40–49秒|纪要/语录/经验进入下次训练|把会议纪要、语录和经验留下来，让下一次练习更有针对性。|
|49–55秒|品牌定格，保持3秒以上|AI职场沟通训练师，把下一次重要沟通，提前练一遍。|

总时长可以根据自然配音微调，建议52–56秒，必须少于60秒。不要为了严格对齐某个秒数而把人声加速。

## 直接发给WorkBuddy的修改指令

请在现有48秒视频的源工程上迭代，保留火柴人形象、企业红/暖白/深灰配色和已完成的动效资产。目标是亮点更醒目、讲述更顺畅，而不是增加更多功能页。

按上面的审阅意见和时间轴修改，重点执行：

- 用“同一次工作沟通”串起问题、训练、复盘和改进。转到表达优化时，用“临时想说的话，也能先整理”作桥接。
- 开场缩短，项目名称第5秒出现；不要让前10秒一直等待气泡。
- 主体放大并居中，尤其问题、原话改写、自然语言输入与结果。去掉无意义的大块空场和漂浮装饰。
- 对象场景用角色与关注点对照；海外片段用一条大号英文问题与中文解读点缀。不是连续阅读网页。
- 六维图表不与完整分数表重复；用原话和具体改法说明评分的价值，所有数值标签一致。
- 表达优化用“这协作真让人头疼。”→“请帮我梳理分歧，明确分工。”，优化句充分停留，不补造事实。
- 直接说必须看清“增加追问强度”→“标准变深入”→“新的追问”三个动作。不能只有输入条，没有结果。
- 资料积累必须连接回下一次训练，形成闭环。
- 不把Skill语音演示、GitHub下载等全部塞进简介视频；PPT后面已有独立展示，简介聚焦核心价值。
- 精简每个镜头的文字，只留有用标题、关键词和原话对照。不生成逐句旁白字幕。
- 保留中文旁白和BGM，先生成自然旁白，再按音轨安排动作。音乐在人声出现时降低音量，音效只强调关键变化。
- 动效结束后的阅读时间，重要元素保持完整清楚可见；淡入淡出只作短转场，不让主体长期处于低透明度。
- 总长建议52–56秒，严格少于60秒。先给完整带声音预览，自行检查旁白是否截断、文字是否可读、动作是否对应，再导出MP4。
