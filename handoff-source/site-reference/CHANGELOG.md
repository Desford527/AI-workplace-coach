# 修改记录

## v1.0 — 2026-10-08

- 新建《AI职场沟通训练师》比赛演示网页，保留原 v4.18 为历史基线。
- 将领导/导师高压叙事改为项目、技术、客户与国际协作的职责导向沟通训练。
- 新增八场景、英文对话中文复盘、明确标注的本地规则演示及完整示例。
- 新增真实 AI 接入、会话取消、请求锁、结构校验、整轮历史配对和失败恢复。
- 新增五维反馈、原话解读、逐轮回看、报告导出与打印。
- 不携带原版密钥、用户数据、测试人物或 Windows 二进制。

## v1.1 — 2026-10-08

- 移除比赛、机构展示标签和API设置；停止本地模板自动回复。
- 补齐双方画像建模、编辑和画像快照；保留自建对象新增、编辑、删除能力。
- 从静态页升级为带D1持久化和用户隔离的Worker；保留原站点。
- 新增Sites MCP训练插件接口，ChatGPT负责实际追问与复盘。
- 新增真实原话评分依据、证据不足待评、逐轮拆解和个性化下一轮重点。
- 新增完整训练历史、复盘导出和文件版资料交接、真实回复录入、JSON复盘导入与备份。

## v1.2 — 2026-10-08

- 个人画像改为AI长期观察展示页，移除自填表与首轮画像前置。
- 复盘指令加入长期画像更新；新增证据化画像写回工具与历史变化。
- 每项特征、优势、提升方向均引用真实回应；方向附具体练法。
- 服务端验证来源用户隔离、记录版本与原话，不接受伪造证据。
- 画像新观察自动用于下一轮训练，历史快照不变。

## v1.3 — 2026-10-08

- 在线网页直接进行AI连续对话，移除核心流程的ChatGPT跳转。
- 后端接入Responses API，模型凭据仅在服务端，未启用时明确禁用训练。
- 自动生成开场、基于完整记录追问、评分复盘及长期画像。
- 新增请求锁、版本验证、成功请求复用与失败重试；画像失败不丢失复盘。
- 使用严格结构输出并继续验证真实原话证据，支持英文训练中文复盘。
- 真实模型启用与生产部署等待安全凭据配置。

## v1.4 — 2026-10-08

- 基础模式不虚构能力评分，也不覆盖已有AI画像。
- 训练模式冻结到记录，后续模型接入不改变已有基础轮次。
