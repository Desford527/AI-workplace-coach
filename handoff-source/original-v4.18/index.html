大模型 API 管理

可保存多个 API 随时切换，模拟答辩用当前选中的 API 驱动（OpenAI 兼容接口）。以 DeepSeek 为例：Base URL 填 https://api.deepseek.com（自动补全 /chat/completions），Key 以 sk- 开头。Key 仅保存在本机，不上传任何第三方。

新增教练

新增或编辑教练：所有字段都会写入本机 skills/ 对应文件（人设 → references 人物档案，其余 → manifest 清单），保存后立即生效。
