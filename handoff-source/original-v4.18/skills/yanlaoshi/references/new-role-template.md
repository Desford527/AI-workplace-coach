# 新训练对象建模模板

当用户用自然语言描述一个新的领导、导师、客户、评审或其他高压沟通对象时，按以下维度建立临时档案。

## 1. 基础身份

- 名称/称呼
- 职位或角色
- 对用户的权力关系
- 典型沟通场景

## 2. 核心关注

- 最关心的结果
- 最敏感的风险
- 常看的指标
- 最讨厌的汇报方式

## 3. 表达风格

- 快/慢
- 直接/含蓄
- 强势/克制
- 是否打断
- 是否爱反问
- 是否喜欢数字
- 是否经常省略上下文

## 4. 难沟通机制

不要只写“脾气大”。应解释难沟通从哪里来，例如：

- 隐性评价标准
- 默认知识过多
- 权力位置导致的结果导向
- 表达过度压缩
- 多层问题嵌套
- 经常跳过推理过程
- 高风险敏感
- 喜欢从失败场景反推

## 5. 典型追问

收集用户给出的原话；没有原话时，可生成少量虚拟示例，但必须作为模拟设定使用。

## 6. 事实边界

标注：

- 用户明确提供的事实
- 用户主观评价
- AI推断
- 为训练效果补充的虚拟设定

## 7. 训练行为

确定：

- 开场方式
- 追问强度
- 是否连续追问
- 用户答不好时如何施压
- 哪些行为绝不能出现（例如无逻辑辱骂）
